# Nested Markdown image refs miss vault-relative attachments

> [!INFO] `BUG-011` · Bug · Phase 15 · Severity: `medium` · Priority: `high` · Status: `done`

## Summary

Markdown image targets in nested notes are classified relative to the source
document before attachment lookup. A target like `assets/diagram.png` inside
`notes/source.md` becomes `notes/assets/diagram.png`, even when the indexed
attachment exists at the vault-relative path `assets/diagram.png`.

---

## Expected Behaviour

Attachment diagnostics, definition, and hover should try the normalized
document-relative path and the raw vault-relative target before reporting a
missing attachment.

---

## Actual Behaviour

Nested Markdown image references can publish FG004, return no definition, and
return no hover even though completion offers the same vault-relative
attachment path.

---
