# willRenameFiles handler does not invoke the refactor pipeline

> [!INFO] `BUG-013` · Bug · Phase 16 · Severity: `medium` · Priority: `high` · Status: `done`

## Summary

`workspace/willRenameFiles` is registered, but the handler still returns
`null`. Now that the planner, rewriter, and validator exist, the handler must
call them and return the validated WorkspaceEdit.

---

## Expected Behaviour

`workspace/willRenameFiles` should convert the workspace root URI to a vault
root path, plan the move, rewrite resolved references, validate the full edit
set, and return the validated WorkspaceEdit. Unsafe or invalid plans should
return `null`.

---

## Actual Behaviour

The handler is a stub and never invokes the Phase 16 refactor pipeline.
