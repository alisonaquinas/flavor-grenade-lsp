# Update Stale Host Test After E15 Language Preservation

> [!SUCCESS] `BUG-047` - Bug - Phase E15 - Severity: `medium` - Status: `done`

## Description

PR #74 CI failed in `npm run test:host`. The stale host test
`extension/src/test/suite/activation-language-mode.test.js` waited for
`document.languageId === "ofmarkdown"`, but E15 deliberately preserves VS Code's
built-in `markdown` language id and moves flavor choice into the selector.

## Root Cause

The host test was legacy E6/E14 proof for language-mode promotion. E15 changed
the expected behavior, but the CI host test still asserted the retired
promotion path.
