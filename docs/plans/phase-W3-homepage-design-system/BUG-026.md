# Mobile Homepage Hero Overflows Viewport

> [!INFO] `BUG-026` · Bug · Phase W3 · Severity: `medium` · Priority: `high` · Status: `done`

## Summary

The mobile homepage visual smoke check shows clipped hero text and horizontal
overflow at a 390px viewport.

## Reproduction Steps

1. Run `npm run build` from `website/`.
2. Run `npm run preview -- --host 127.0.0.1 --port 4173` from `website/`.
3. Capture `http://127.0.0.1:4173/` at a 390px wide viewport.

## Expected Behaviour

The mobile homepage should not horizontally overflow or clip the category,
hero, CTA, or proof-panel content.

## Actual Behaviour

The captured mobile screenshot clips the category text and hero lede at the
right edge.

## Violated Requirement

| Planguage Tag | Gist | Source File |
|---|---|---|
| `Website.Mobile.CoreUseCases` | Mobile visitors can identify product, reach setup, and inspect proof without horizontal overflow | [[website/docs/requirements/functional/mobile-and-responsive]] |

## Proposed Fix

Add a mobile layout regression guard and constrain hero/proof content so long
strings wrap, grids can shrink, and the page clips accidental horizontal
overflow.
