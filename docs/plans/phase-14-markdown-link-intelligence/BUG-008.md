# BDD smoke includes pending scenarios

> [!INFO] `BUG-008` · Bug · Phase 14 · Severity: `medium` · Priority: `high` · Status: `in-progress`

## Summary

The `@smoke` BDD gate exits non-zero after assertion failures are fixed because
several smoke-tagged scenarios still return `pending`.

---

## Reproduction Steps

1. Run `bun --bun node_modules/@cucumber/cucumber/bin/cucumber-js --config cucumber.yaml --tags '@smoke'`.
2. Observe zero failed assertions but a non-zero exit due to pending steps.

**Minimal reproducing vault content:**

```markdown
notes/index.md
```

**LSP method / trigger:** BDD smoke gate

---

## Expected Behaviour

The server repo `@smoke` gate should contain only runnable scenarios whose step
definitions return pass/fail results, not `pending`.

---

## Actual Behaviour

The smoke gate includes scenarios with pending steps in vault detection, tag,
and code-action coverage, causing Cucumber to exit non-zero.
