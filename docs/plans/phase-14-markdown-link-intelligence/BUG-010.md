# Standalone Markdown link definitions are missing from RefGraph document refs

> [!INFO] `BUG-010` · Bug · Phase 14 · Severity: `high` · Priority: `high` · Status: `in-progress`

## Summary

`LinkLabelDef` entries are parsed but standalone definitions such as
`[alpha]: alpha.md` are not registered in `markdownRefsToMap` unless there is a
matching label use.

---

## Reproduction Steps

1. Parse a source document containing only `[alpha]: alpha.md`.
2. Add `alpha.md` to the `VaultIndex`.
3. Rebuild `RefGraph`.
4. Query `getMarkdownRefsTo("notes/alpha")`.

**Minimal reproducing vault content:**

```markdown
[alpha]: alpha.md
```

**LSP method / trigger:** RefGraph rebuild

---

## Expected Behaviour

The link definition should appear as a Markdown document reference to
`notes/alpha`.

---

## Actual Behaviour

The definition is absent from `markdownRefsToMap`.
