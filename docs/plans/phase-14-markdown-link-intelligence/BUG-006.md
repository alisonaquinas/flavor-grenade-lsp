# BDD smoke indexes files outside configured extension list

> [!INFO] `BUG-006` · Bug · Phase 14 · Severity: `medium` · Priority: `high` · Status: `in-review`

## Summary

The `@smoke` BDD scenario `.flavor-grenade.toml configures custom extension list`
indexes `note.rst` even though the scenario config allows only `.md`,
`.markdown`, and `.txt`.

---

## Reproduction Steps

1. Run `bun --bun node_modules/@cucumber/cucumber/bin/cucumber-js --config cucumber.yaml --tags '@smoke'`.
2. Observe `docs/bdd/features/vault-detection.feature:75` fail.

**Minimal reproducing vault content:**

```toml
[vault]
extensions = [".md", ".markdown", ".txt"]
```

**LSP method / trigger:** initial vault scan

---

## Expected Behaviour

The document index should include only files whose extensions match the
configured extension list.

---

## Actual Behaviour

The document index contains `custom/notes/note.rst`.

---
