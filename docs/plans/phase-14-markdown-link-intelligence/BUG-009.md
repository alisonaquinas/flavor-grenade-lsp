# Documented BDD smoke command does not reproduce on PowerShell

> [!INFO] `BUG-009` · Bug · Phase 14 · Severity: `medium` · Priority: `high` · Status: `in-review`

## Summary

The Phase Execution Procedure documents `bun run bdd -- --tags @smoke`, but
that form fails on PowerShell/Bun because the Cucumber `--tags` option receives
no expression argument.

---

## Reproduction Steps

1. Run `bun run bdd -- --tags @smoke` in PowerShell.
2. Observe Cucumber report `option '-t, --tags <EXPRESSION>' argument missing`.
3. Run `bun run bdd --tags "@smoke"` and observe the smoke suite pass.

**Minimal reproducing vault content:**

```markdown
notes/index.md
```

**LSP method / trigger:** BDD smoke gate

The documented Phase L smoke command should reproduce on the local development
