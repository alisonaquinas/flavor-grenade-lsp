# Markdown index fields crash legacy OFMDoc fixtures

> [!INFO] `BUG-002` · Bug · Phase 14 · Severity: `high` · Priority: `high` · Status: `in-progress`

---

## Summary

Handlers and RefGraph crash when they receive OFMDoc test fixtures that predate
the Phase 14 Markdown index arrays.

---

## Reproduction Steps

1. Run `bun test` on the Phase 14 branch.
2. Observe existing CodeLens, cursor entity, references, rename, diagnostics,
   and RefGraph tests fail.
3. Inspect the first stack traces in `src/resolution/ref-graph.ts` and
   `src/handlers/cursor-entity.ts`.

**Minimal reproducing vault content:**

```markdown
# Alpha

[[Beta]]
```

**LSP method / trigger:** `bun test`

---

## Expected Behaviour

Phase 14 Markdown link support should be additive. Existing wiki-link,
diagnostic, navigation, rename, and RefGraph tests should continue to pass when
their focused OFMDoc fixtures omit newly-added Markdown link arrays.

---

## Actual Behaviour

`bun test` fails with `TypeError: undefined is not an object` while iterating
`doc.index.markdownLinks`, `markdownImages`, `linkLabelRefs`, or
`linkLabelDefs`.

## Proposed Fix

read OFMDoc fixtures, preserving existing tests while parsed production docs
continue to provide the arrays.
