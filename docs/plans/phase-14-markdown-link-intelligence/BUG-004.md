# Malformed Markdown anchor escapes can crash heading resolution

> [!INFO] `BUG-004` · Bug · Phase 14 · Severity: `high` · Priority: `high` · Status: `open`

## Summary

`normalizeHeadingAnchor` calls `decodeURIComponent` on user-controlled Markdown
fragments, so malformed percent escapes such as `[x](#%)` throw `URIError`.

---

## Reproduction Steps

1. Call `normalizeHeadingAnchor('%')`.
2. Observe `URIError: URI malformed`.
3. The same path is reachable from Markdown diagnostics/navigation for
   `[x](#%)`.

**Minimal reproducing vault content:**

```markdown
[Broken](#%)
```

**LSP method / trigger:** Markdown heading diagnostics, definition, references,
rename, or heading completion.

---

## Expected Behaviour

Malformed percent escapes should not crash the server. They should normalize
with a safe fallback and resolve as missing or nonmatching anchors.

---

## Actual Behaviour

`decodeURIComponent` throws before resolution can return a normal result.
