# BDD smoke includes undefined extension-host scenario

> [!INFO] `BUG-007` · Bug · Phase 14 · Severity: `medium` · Priority: `high` · Status: `in-review`

## Summary

The `@smoke` BDD gate includes `VS Code extension lifecycle and integration`
even though the extension-host steps are not implemented in this server repo.

---

## Reproduction Steps

1. Run `bun --bun node_modules/@cucumber/cucumber/bin/cucumber-js --config cucumber.yaml --tags '@smoke'`.
2. Observe `docs/bdd/features/vscode-extension.feature:17` report undefined
   steps.

**Minimal reproducing vault content:**

```markdown
notes/welcome.md
```

**LSP method / trigger:** BDD smoke gate

---

## Expected Behaviour

The server repo `@smoke` gate should include only scenarios with implemented
step definitions or mark extension-host scenarios outside the server smoke gate.

---

## Actual Behaviour

The smoke gate exits non-zero because extension-host steps are undefined.
