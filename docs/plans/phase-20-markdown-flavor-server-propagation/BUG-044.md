# Restore OFM BDD Vault Flavor After CommonMark Fallback

> [!SUCCESS] `BUG-044` - Bug - Phase 20 - Severity: `high` - Status: `done`

## Finding

`bun run bdd` failed 35 scenarios after Phase 20 changed empty
`.flavor-grenade.toml` project evidence to fall through to CommonMark. The BDD
harness creates OFM behavior scenarios with a Flavor Grenade vault marker, so
wiki-link, embed, block-reference, diagnostics, navigation, document-link, and
rename scenarios no longer parse Obsidian-only syntax.

## Fix Plan

- Keep the production fallback semantics from
  `docs/design/markdown-flavor-auto-detection.md`.
- Update source-owned BDD vault setup to mark legacy OFM scenarios as Obsidian
  vaults explicitly, rather than relying on empty project TOML as an implicit
  Obsidian signal.
- Rerun `bun run bdd`.

## Workflow Log

> Ticket opened before fixing the BDD failure found in the Phase 20 gate.

> [!SUCCESS] Fixed - 2026-05-13
> Legacy OFM BDD fixtures now write explicit Obsidian project flavor in
> `.flavor-grenade.toml`. `bun run bdd` passes with 178 scenarios.
