# Tag Reference BDD Includes Nested Tag Occurrence

> [!INFO] `BUG-035` · Bug · Phase 18 · Severity: `high` · Priority: `high` · Status: `open`

## Summary

The BDD assertion for `#topic-one` references detects `#topic-one/sub` in the
returned locations.

## Reproduction Steps

1. Run `bun run bdd`.
2. Observe `docs/bdd/features/navigation.feature`.
3. The `#topic-one/sub` exclusion assertion fails.

## Expected Behaviour

Find-references for `#topic-one` should not return the nested tag
`#topic-one/sub` unless the requirement intentionally treats parent tags as
hierarchical matches.

## Actual Behaviour

The scenario reports `#topic-one/sub` as included in the references.
