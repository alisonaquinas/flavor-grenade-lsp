# Restore Full BDD Suite Execution

> [!INFO] `BUG-033` · Bug · Phase 18 · Severity: `high` · Priority: `high` · Status: `in-review`

## Summary

`bun run bdd` exits 1 because the checked-in Cucumber suite still contains
undefined and pending scenarios.

## Reproduction Steps

1. Run `bun run bdd` from the repository root.
2. Wait for the Cucumber run to complete.
3. Observe the non-zero exit and undefined/pending scenario summary.

**Minimal reproducing vault content:**

```markdown
N/A - the failure is caused by missing or pending Cucumber step definitions.
```

**LSP method / trigger:** `bun run bdd`

## Expected Behaviour

All BDD scenarios either execute with implemented step definitions or are
removed from the default gate until their implementation phase owns them.

## Actual Behaviour

The verification run reported 149 scenarios total, with 91 passed, 34
undefined, and 24 pending. Cucumber exited with code 1.

definitions with RED/GREEN commits or tag intentionally future scenarios out of
the default BDD gate with explicit tracking tickets.
