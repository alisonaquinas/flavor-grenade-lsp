# BDD File Watcher Scenario Fails On Linux CI Precondition

> [!INFO] `BUG-041` · Bug · Phase 18 · Severity: `high` · Priority: `high` · Status: `verified`

## Summary

The new `BDD scenarios` CI job fails on Linux before the file-creation assertion:
the harness writes five existing Markdown files after server startup, but the
index does not observe them within the precondition wait.

## Reproduction Steps

1. Push TASK-282 CI expansion to PR #65.
2. Observe GitHub Actions run `25708443397`.
3. Open the `BDD scenarios` job.

## Expected Behaviour

The default BDD gate should pass on Linux CI with all checked-in scenarios and
steps passing.

## Actual Behaviour

`docs/bdd/features/workspace.feature:101` fails at `And the vault currently has
5 documents`. The assertion expected the indexed document predicate to be true
after writing the five documents, but it remained false. Cucumber reported 149
scenarios total, 148 passed, 1 failed, 3 skipped steps, and exit code 1.
