# Extension Host Test Blocked By VS Code Update Mutex

> [!INFO] `BUG-042` · Bug · Phase 18 · Severity: `medium` · Priority: `medium` · Status: `in-review`

## Summary

`npm run test:host` failed during Phase 18 local verification because the VS
Code test runtime could not launch while the Windows `vscode-updating` mutex was
held.

## Reproduction Steps

1. Run `npm run test:host` from `extension/`.
2. Wait for `@vscode/test-electron` to resolve and launch VS Code.
3. Observe that VS Code exits before extension-host tests run.

**Minimal reproducing vault content:**

```markdown
N/A - the failure occurs before the extension-host fixture opens.
```

**LSP method / trigger:** extension-host verification command.

## Expected Behaviour

The extension-host gate launches VS Code and runs the host regression suite.

## Actual Behaviour

VS Code reported `Code is currently being updated. Please wait for the update
to complete before launching.` after waiting roughly 30 seconds on the
`vscode-updating` mutex.

## Proposed Fix

Triage whether this is a transient local VS Code updater lock or a repeatable
host-test harness issue. If transient, rerun after the external lock clears and
close as out of scope for repository code. If repeatable, add a harness retry or
preflight check before the host test launch.
