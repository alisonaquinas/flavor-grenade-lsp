# Workspace BDD File Watcher Update Misses 500ms Index Window

> [!INFO] `BUG-039` · Bug · Phase 18 · Severity: `high` · Priority: `high` · Status: `in-progress`

## Summary

`bun run bdd` failed during CHORE-102 verification because the workspace file
watcher scenario did not observe a newly created Markdown file in the index
within 500ms.

## Reproduction Steps

1. Run `bun run bdd` from the repository root.
2. Observe `docs/bdd/features/workspace.feature`.
3. The scenario `File watcher detects new file creation and updates index`
   fails at `Then within 500ms the document index contains
   "notes/new-note.md"`.

## Expected Behaviour

The BDD harness should either observe a real watcher update within the specified
window or use a deterministic synchronization point that proves the index has
processed the file creation before the assertion.

## Actual Behaviour

The assertion received `false` for `document index contains "notes/new-note.md"`
within 500ms. Cucumber reported 149 scenarios total, 148 passed, 1 failed, 1
skipped step, and exit code 1.
