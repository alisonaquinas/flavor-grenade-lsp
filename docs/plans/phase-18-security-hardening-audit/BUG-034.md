# Code Action BDD Command Execution Is Unimplemented

> [!INFO] `BUG-034` · Bug · Phase 18 · Severity: `high` · Priority: `high` · Status: `verified`

## Summary

The BDD scenario for executing `fg.createMissingFile` fails because
`workspace/executeCommand` returns `Unknown command: fg.createMissingFile`.

## Reproduction Steps

1. Run `bun run bdd`.
2. Observe `docs/bdd/features/code-actions.feature`.
3. The create-missing-file execution step fails after the quick-fix action is
   offered.

## Expected Behaviour

The BDD harness must verify the expected apply-edit payload or the server must
implement the command path exercised by the scenario.

## Actual Behaviour

The response is `{"code":-32603,"message":"Unknown command: fg.createMissingFile"}`.
