# Restore Spawned LSP Integration Test Responses

> [!INFO] `BUG-024` · Bug · Phase 18 · Severity: `high` · Priority: `high` · Status: `triaged`

## Summary

All spawned-server integration tests time out waiting for LSP responses during
the Phase 18 verification sweep.

---

## Reproduction Steps

1. Run `bun test src/test/integration/transport.test.ts`.
2. Wait for the command timeout.
3. Repeat with the other `src/test/integration/*.test.ts` files.

**Minimal reproducing vault content:**

```markdown
N/A - transport handshake hangs before fixture-specific assertions.
```

**LSP method / trigger:** `initialize` request over stdio.

---

## Expected Behaviour

The integration harness spawns the server, receives an `initialize` response,
and exits within each test's configured timeout.

---

## Actual Behaviour

Every `src/test/integration/*.test.ts` file timed out at the command level while
waiting for a spawned server response.

## Proposed Fix

plain primitive constructor dependency, while preserving direct test
construction with a small scan limit.
