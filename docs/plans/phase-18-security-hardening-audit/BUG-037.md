# VS Code Extension BDD Harness Has Ambiguous And Missing Steps

> [!INFO] `BUG-037` · Bug · Phase 18 · Severity: `high` · Priority: `high` · Status: `verified`

## Summary

Extension BDD scenarios fail because harness-only steps are ambiguous, missing,
or attempt to use the real stdio transport when no server process exists.

## Reproduction Steps

1. Run `bun run bdd`.
2. Observe `docs/bdd/features/ofmarkdown-language-mode.feature`,
   `vscode-extension.feature`, and `vscode-extension-parity.feature`.
3. The run reports ambiguous `the user opens` steps, missing status reset steps,
   and null stdio process errors.

## Expected Behaviour

Extension feature scenarios should execute against deterministic extension
harness state or a real extension-host test, but not remain undefined.

## Actual Behaviour

The default BDD gate reports ambiguous, undefined, and failed extension steps.
