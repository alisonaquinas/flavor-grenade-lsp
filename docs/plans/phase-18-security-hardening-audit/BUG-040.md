# Extension CI Package-Target Check Lacks Bundled Server Binary

> [!INFO] `BUG-040` · Bug · Phase 18 · Severity: `high` · Priority: `high` · Status: `in-review`

## Summary

The new `Extension checks` CI job fails in a clean Linux runner because the
extension package-target test expects a bundled Windows server binary, but the
job only builds the extension client before running package validation.

## Reproduction Steps

1. Push TASK-282 CI expansion to PR #65.
2. Observe GitHub Actions run `25708443397`.
3. Open the `Extension checks` job.

## Expected Behaviour

The extension CI job should build or stage the server binary required by
`extension/test/package-targets/server-binary.test.ts` before running `npm test`
or `npm run verify:package-targets`.

## Actual Behaviour

`npm test` fails while inspecting a packaged `win32-x64` VSIX with:
`missing server binary for win32-x64: expected
extension/server/flavor-grenade-lsp.exe`.
