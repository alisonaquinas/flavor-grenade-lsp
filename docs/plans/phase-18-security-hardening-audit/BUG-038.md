# Vault Detection BDD Scope Assertion Is Too Strict

> [!INFO] `BUG-038` · Bug · Phase 18 · Severity: `medium` · Priority: `medium` · Status: `in-review`

## Summary

The nested `.obsidian/` BDD scenario fails at the harness assertion that every
indexed doc id appears under `outer/inner/`, even though doc ids are
vault-relative and may not include the root path prefix.

## Reproduction Steps

1. Run `bun run bdd`.
2. Observe `docs/bdd/features/vault-detection.feature`.
3. The `vault index is scoped to "outer/inner/" only` assertion fails.

## Expected Behaviour

The assertion should verify no outer-only documents are indexed while allowing
vault-relative doc ids.

## Actual Behaviour

The assertion rejects valid vault-relative doc ids that do not include the root
directory prefix.
