# Expand Website Guide Article Prose

> [!WARNING] `BUG-031` · Bug · Phase W7 · Severity: `medium` · Status:
> `in-review`

## Problem

Review feedback found that the new article pages are too brief for public
documentation. The server-only install path needs concrete npm instructions,
the VS Code install path needs an explicit Marketplace link, and article
sections need real explanatory prose plus practical examples.

## Root Cause

Phase W7 shipped the article route structure and first-pass prose, but many
sections were still compact planning copy. The renderer also treated each
section body as a single paragraph, which made longer article prose awkward.

## Fix Plan

1. Add regression tests for npm server install instructions, Marketplace-linked
   VS Code install instructions, and multi-paragraph article section prose.
2. Render section body text as separate paragraphs.
3. Expand how-to, concept, and advanced article sections with at least one to
   two paragraphs and concrete examples where the first pass was stub-like.
4. Re-run website and documentation gates.
