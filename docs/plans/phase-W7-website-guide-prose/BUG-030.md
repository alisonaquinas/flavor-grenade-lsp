# Restore Website Guide Regression Expectations

> [!WARNING] `BUG-030` · Bug · Phase W7 · Severity: `medium` · Status: `done`

## Problem

Full website tests caught regressions after the Phase W7 content replacement:

- The quickstart page no longer exposed its Troubleshooting section.
- The VS Code extension article no longer exposed the exact "Install from the
  Visual Studio Marketplace" section heading or "vault open" wording.
- The Advanced Usage hub and advanced article examples needed to retain the
  existing boundary terms required by tests.
- The maintained sitemap needed to match the expanded typed route metadata.

## Root Cause

The content rewrite replaced the old page records wholesale, so several
existing regression-test phrases and the maintained crawl file drifted while
new article routes were added.

## Fix Plan

1. Restore the required quickstart and VS Code extension wording.
2. Keep advanced usage article text aligned with boundary tests.
3. Keep `website/public/sitemap.xml` aligned with `websiteRoutes`.
4. Re-run the full website test suite.
