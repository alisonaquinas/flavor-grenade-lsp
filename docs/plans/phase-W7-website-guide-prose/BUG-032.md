# Deepen Website Article Prose Beyond First-pass Copy

> [!WARNING] `BUG-032` · Bug · Phase W7 · Severity: `medium` · Status:
> `in-review`

## Problem

The article pages now support multiple paragraphs and npm server install
instructions, but too much prose still comes from generic helper text. The
articles need more page-specific explanation, setup context, and examples so
they read like public guide articles instead of route stubs.

## Root Cause

The Phase W7 content model used shared helper functions to create many article
pages quickly. That gave every article the required shape, but it also made
sections sound repetitive and left some examples too compact.

## Fix Plan

1. Add tests that catch repeated generic helper prose and enforce deeper article
   bodies.
2. Replace generic second paragraphs with article-specific prose for how-to and
   concept pages.
3. Expand advanced pages with concrete setup, boundary, and troubleshooting
   examples.
4. Run website and documentation gates.
