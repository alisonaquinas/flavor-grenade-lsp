# Mobile Docs Pages Clip Long Content

> [!INFO] `BUG-027` · Bug · Phase W4 · Severity: `medium` · Priority: `high` · Status: `done`

## Summary

The quickstart docs page clips paragraph and list text horizontally at a 390px
mobile viewport.

## Reproduction Steps

1. Run `npm run build` from `website/`.
2. Run `npm run preview -- --host 127.0.0.1 --port 4173` from `website/`.
3. Capture `http://127.0.0.1:4173/quickstart/` at a 390px wide viewport.

## Expected Behaviour

Docs-page copy, list items, steps, and code snippets should wrap or scroll
inside their own containers without clipping the viewport.

## Actual Behaviour

The mobile quickstart screenshot clips the summary and prerequisite list text at
the right edge.

## Violated Requirement

| Planguage Tag | Gist | Source File |
|---|---|---|
| `Website.Mobile.CoreUseCases` | Mobile visitors can identify product, reach setup, and inspect proof without horizontal overflow | [[website/docs/requirements/functional/mobile-and-responsive]] |

## Linked Test

| Test File | Type | Status |
|---|---|---|
| `website/tests/docs-mobile-layout.test.ts` | Unit | ✅ passing |

## Proposed Fix

Add a docs-page mobile layout regression guard and constrain docs hero, section,
list, and related-link content with shrink and wrapping rules.
