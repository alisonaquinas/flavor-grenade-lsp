# Website Content Scripts

This directory contains small CLI entry points for generating and validating
website content artifacts.

## Files

| File | Responsibility |
|---|---|
| `generate.ts` | Runs the website content build and writes generated modules. |
| `check.ts` | Verifies generated content is current and valid. |
