# Flavor Grenade LSP

Flavor Grenade LSP helps VS Code understand the Obsidian-style links, tags, and attachments in your Markdown vault.

## A friendlier editor for connected notes

Use it when your notes are more than plain text: wiki links point to other notes, tags carry meaning across the vault, and embeds bring local files into the page. Flavor Grenade turns those relationships into helpful editor features like completion, navigation, references, rename, and broken-link warnings.
