# Quickstart User Requirements

## User Need

Users must be able to install or evaluate Flavor Grenade quickly and confirm
that it is working in a real vault or workspace.

## Required Experience

The quickstart must cover both primary entry paths:

- VS Code extension users.
- Direct LSP server users.

It must move from prerequisite check to installation, workspace setup,
verification, and first useful actions.

## Acceptance Criteria

- The quickstart lists prerequisites for VS Code extension and direct server
  use.
- The quickstart explains the recommended VS Code extension install path.
- The quickstart links to
  [Flavor Grenade LSP on the Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=alisonaquinas.flavor-grenade-lsp).
- The quickstart explains how to open an Obsidian Vault folder in VS Code.
- The quickstart explains how to confirm that a vault Markdown file is using
  OFMarkdown mode.
- The quickstart explains the direct LSP server install path.
- The quickstart includes copyable commands or configuration snippets where
  useful.
- The quickstart explains minimal vault setup.
- The quickstart explains how to confirm indexing or server readiness.
- The quickstart includes first actions:
  - complete a wiki-link
  - hover or navigate a link
  - find references
  - rename a note
  - observe a broken-link diagnostic
- The quickstart links to troubleshooting content for activation, workspace
  trust, binary path, and indexing problems.
- The page avoids protocol details unless they are required to complete setup.
