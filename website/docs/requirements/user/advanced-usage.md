# Advanced Usage User Requirements

## User Need

Advanced users must understand configuration, integration boundaries, and
runtime behavior well enough to adopt Flavor Grenade in non-trivial workflows.

## Required Experience

Advanced usage content must explain the system without exposing unnecessary
internal planning details. It should help users reason about editor
integrations, vault behavior, performance, and safety boundaries.

## Acceptance Criteria

- Advanced usage explains the server configuration model.
- The Advanced Usage hub links each major section heading to a dedicated
  advanced-topic article.
- Advanced usage explains editor integration beyond VS Code when supported or
  planned.
- Advanced usage explains vault mode and single-file mode.
- Advanced usage explains vault indexing behavior and performance expectations.
- Advanced usage explains unsupported URI schemes and vault confinement.
- Advanced usage explains OFM parser boundaries, including opaque regions.
- Advanced usage explains extension/server version compatibility.
- Advanced usage explains CI or scripted diagnostics workflows if supported.
- Advanced usage links to concept pages for OFM, vault index, link resolution,
  and local target safety.
- Advanced usage distinguishes current behavior from planned behavior.
- The desktop Advanced Usage navigation item provides a hover and focus
  dropdown linking to advanced-topic article pages.
