# Website Functional Requirements

## Purpose

These are Planguage-style functional requirements for the Flavor Grenade public
website. They turn the project brief, user requirements, design requirements,
and technical requirements into testable website behavior.

complete required set. Requirements that depend on future implementation
decisions keep open questions instead of fake precision.
